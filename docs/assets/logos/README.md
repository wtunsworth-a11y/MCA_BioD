# Logos

Upload partner and funder logos here (PNG or SVG, ideally on a
transparent background, at least 200 px tall), then list them in
`docs/data/config.json` under `logos`, for example:

    "logos": [
      {"file": "assets/logos/eu-funded-by.png", "alt": "Funded by the European Union"},
      {"file": "assets/logos/la.png", "alt": "<partner name>"}
    ]

They appear in the site footer, in the order listed.
